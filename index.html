About eon games

A one-person studio building games that run entirely in a browser tab. Every title here is Free

Learning curve

No game engine and no framework. Each game is plain JavaScript, written and tested in the browser it runs in.

Plays anywhere

Desktop, tablet or phone. The multiplayer games take touch controls as well as mouse, keyboard and a controller.

Free, with no catch
